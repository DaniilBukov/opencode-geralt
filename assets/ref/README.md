# Референсный клип

Здесь должен лежать `0x0011bb5c.wav` — фрагмент русской озвучки Геральта
(около 9 секунд чистой речи, без музыки и эффектов).

В репозитории клипа нет: это игровая озвучка, только для личного
использования. В git он не попадёт (`.gitignore`).

Если файла нет:

1. Положите свой клип сюда (WAV, 10–15 секунд чистой речи одного голоса).
2. Укажите путь через `F5_REF` или замените имя файла в `f5_server.py`.
3. Обновите `REF_TEXT` (или `F5_REF_TEXT`): расшифровка должна дословно
   совпадать с тем, что звучит в клипе, иначе качество клонирования падает.
