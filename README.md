# Geralt voice for OpenCode (F5-TTS Russian)

Локальный русский голос Геральта для ответов OpenCode. Синтез идёт через
[F5-TTS Russian v2](https://huggingface.co/Misha24-10/F5-TTS_RUSSIAN)
(zero-shot клонирование по одному референсному клипу), без облака.

Репозиторий самодостаточен: код, скрипты установки, референсный клип и
шаблон конфига. Тяжёлые вещи (venv, веса модели) создаются установщиком.

## Структура

```text
voice-tts/
├── index.ts               плагин OpenCode (озвучка ответов, playback)
├── f5_server.py           постоянный воркер F5-TTS (HTTP, порт 8766)
├── tts_f5.py              CLI для плагина: стартует/переиспользует воркер
├── f5_pronounce.json      словарь произношения (ударения, перезапись)
├── package.json           манифест плагина
├── play.ps1, sapi.ps1     Windows-fallback воспроизведения/SAPI
├── assets/ref/            референсный клип (кладётся вручную, в git не входит)
├── models/                веса F5 (скачиваются, в git не попадают)
├── runtime/venv/          python-окружение (создаётся install.py)
├── scripts/
│   ├── install.py         установка под текущую ОС
│   ├── fetch_model.py     загрузка весов с HuggingFace
│   └── patch_ruaccent.py  патч ruaccent под новые transformers
├── docs/opencode.json.example
├── legacy/               старые обвязки (SVC, Edge TTS), не используются
└── requirements.txt
```

## Требования

| | |
|---|---|
| Python | 3.10–3.12 (рекомендуется 3.12) |
| GPU | NVIDIA + CUDA 12.4 — быстро (~5–15 с на ответ); CPU работает, но медленно |
| macOS | Apple Silicon (MPS) или CPU; `afplay` для воспроизведения |
| Linux | `ffmpeg` (`ffplay`) или `alsa-utils` (`aplay`) для воспроизведения |
| OpenCode | плагины включены, конфиг `~/.config/opencode/opencode.json` |

## Установка на новой машине

1. Скопировать (или `git clone`) эту папку в `~/.config/opencode/voice-tts`.
   На Windows это `%USERPROFILE%\.config\opencode\voice-tts`.

2. Поставить окружение и веса:

```bash
# NVIDIA (Windows/Linux)
python scripts/install.py

# только CPU
python scripts/install.py --cpu

# macOS
python scripts/install.py
```

Скрипт создаёт `runtime/venv`, ставит torch под текущую ОС, остальные
зависимости, патчит `ruaccent`, качает модель в `models/f5` и печатает
готовый блок для `opencode.json` с абсолютными путями этой машины.

3. Положить референсный клип в `assets/ref/` (в репозитории его нет — см.
   `assets/ref/README.md`). Без клипа воркер не запустится.

4. Вставить напечатанный блок в массив `plugins` в `~/.config/opencode/opencode.json`
   (пример — `docs/opencode.json.example`). Поле `package` должно указывать на
   имя папки: `"./voice-tts"`, если папка называется `voice-tts`.

5. Перезапустить OpenCode. Первый ответ будет с задержкой ~40–60 с (загрузка
   модели в память), дальше 5–15 с на ответ.

Проверка без OpenCode:

```bash
# Windows
runtime\venv\Scripts\python.exe tts_f5.py --out test.wav --text "Проверка связи"

# Linux/macOS
runtime/venv/bin/python tts_f5.py --out test.wav --text "Проверка связи"
```

## Настройки

Параметры командной строки `tts_f5.py`:

| флаг | смысл |
|---|---|
| `--speed 1.0` | темп речи (0.8 медленнее, 1.1 быстрее); зависит от референса |
| `--nfe 32` | шагов сэмплирования; 48 чётче, но медленнее |
| `--warm` | поднять воркер и выйти (плагин делает это при старте) |
| `--stop` | остановить воркер и освободить память |
| `--out`, `--textfile`, `--text` | куда писать и откуда читать текст |

Переменные окружения воркера:

| переменная | по умолчанию |
|---|---|
| `F5_PORT` | `8766` |
| `F5_DEVICE` | авто: `cuda` → `mps` → `cpu` |
| `F5_CKPT`, `F5_VOCAB` | `models/f5/...` |
| `F5_REF`, `F5_REF_TEXT` | `assets/ref/0x0011bb5c.wav` + его расшифровка |
| `F5_SPEED`, `F5_NFE` | `1.0`, `32` |
| `F5_IDLE_TIMEOUT` | `1800` — секунд простоя до выгрузки, `0` отключает |
| `F5_PYTHON` | интерпретатор для `tts_f5.py` (иначе `runtime/venv`) |

## Словарь произношения

`f5_pronounce.json` — ключ: слово в тексте, значение: как произнести.
`+` ставится перед ударной гласной, можно писать фонетическую перезапись:

```json
{
  "ривии": "Р+ивии",
  "властно": "вл+асно",
  "синтез": "с+интэз"
}
```

Применяется после расстановки ударений, поэтому перекрывает автоматику.
Перечитать словарь без перезапуска модели:

```bash
curl http://127.0.0.1:8766/reload
```

## Стиль ответов «Геральт» (опционально)

`docs/geralt-style.md` — промпт стиля: лексика, обороты, ритм. Живёт отдельно
от плагина голоса, включается в конфиге OpenCode.

```powershell
# Windows
Copy-Item docs\geralt-style.md "$env:USERPROFILE\.config\opencode\geralt-style.md"
```

```bash
# Linux / macOS
cp docs/geralt-style.md ~/.config/opencode/geralt-style.md
```

Затем в `~/.config/opencode/opencode.json`:

```json
"instructions": [
  "~/.config/opencode/geralt-style.md"
]
```

Отключить — убрать ключ `instructions` (файл можно оставить).

## Как это работает

1. `normalize_numbers()` — числа, годы, диапазоны, единицы (`16 ГБ`), валюты,
   сокращения (`т.д.`, `см.`, `№`).
2. `transliterate_latin()` — английские слова и имена файлов в кириллицу
   (`opencode.json` → «оупенкоуд джейсон»).
3. `ruaccent` — ударения; затем словарь исключений.
4. Текст режется на предложения/клаузы; паузы: `.` 0.38 с, `…` 0.55 с,
   `;`/`:` 0.26 с, `—` 0.22 с, абзац 0.45 с.
5. Блоки по ~200 символов уходят в F5 одним вызовом, тишина на краях
   обрезается, чтобы паузы не удваивались.
6. Воркер живёт между запросами, поэтому модель грузится один раз.

Отклик:

- при старте плагин прогревает воркер (`tts_f5.py --warm`), первый ответ без
  минутной задержки;
- следующий кусок синтезируется, пока играет текущий (предзагрузка);
- звук строго по очереди: новый ответ перебивает старый, два голоса
  одновременно не звучат.

## Перенос на другую ОС

- **venv переносить нельзя** — он привязан к ОС и пути. На новой машине
  `scripts/install.py` создаёт его заново.
- **Веса модели** можно не качать повторно: скопируйте `models/f5/`
  (около 1.3 ГБ) или дайте `fetch_model.py` скачать.
- `runtime/`, `models/`, `engines/` в git не попадают (`.gitignore`).
- Конфиг OpenCode генерируется установщиком — пути будут уже правильные.

## Диагностика

| симптом | что делать |
|---|---|
| тишина в ответах | `tail` лога `%TEMP%/opencode-voice-tts/plugin.log` (Linux/macOS: `/tmp/...`) |
| `process timed out` | поднять `timeoutMs` или уменьшить `maxChars` |
| первый ответ очень долгий | модель грузится; прогреть: `curl http://127.0.0.1:8766/health` |
| «роботизированно» / торопливо | сменить `F5_REF` на более спокойный клип и подобрать `--speed` |
| нет звука на Linux | поставить `ffmpeg` или `alsa-utils` |
| `Missing Input: token_type_ids` | `python scripts/patch_ruaccent.py` |

### Память

Воркер живёт отдельным процессом и **не выгружается** при закрытии OpenCode.
Чтобы память не висела зря, он сам выгружается после 30 минут без запросов
(`F5_IDLE_TIMEOUT`, в секундах; `0` отключает авто-выгрузку). Выгрузка
происходит только когда нет активного синтеза.

Освободить вручную:

```bash
runtime/venv/bin/python tts_f5.py --stop
```

Поднять снова (или дождаться первого ответа):

```bash
runtime/venv/bin/python tts_f5.py --warm
```

Изменение таймаута — переменной окружения перед запуском OpenCode, например
`F5_IDLE_TIMEOUT=600` для 10 минут.
